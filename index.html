How-To & Privacy

100% Private, Free & Offline

No account, no login, no ads, and zero tracking.
Everything runs locally in your browser.

When you tap + File, ChoreoLoop can either save a local copy in IndexedDB (instant offline switch) or stream directly without copying (0 MB storage, ideal for long videos).
Your loops, BPM, and bookmarks are always saved per file.
Nothing is ever uploaded to a server, and your original file is never changed or deleted.

Supported Formats:

  • Audio: MP3, M4A, WAV, AAC, OGG
  • Video: MP4, MOV, WebM

Local Files vs. YouTube Links

Feature Local File YouTube Link
Works Offline Yes (saved locally) Not supported by YouTube
Mirror Mode & Fullscreen Yes Not supported by YouTube
Slow-Motion Speed Smooth 0.25x - 1.25x Fixed API steps (0.25x, 0.5x, 0.75x, 1.0x, 1.25x)
A-B Loop & Bookmarks Yes (frame-accurate) Yes (online buffering)

Save as an App & Use Offline

iPhone / iPad (Safari): Tap Share → Add to Home Screen.
Android (Chrome / Samsung Internet): Tap browser Menu (⋮) → Install app / Add to Home screen.

Icon Tip: Pick Dark Mode (White Hat) or Light Mode (Black Hat) before saving to use that icon on your Home Screen.

Offline Tip: Before heading into a dance studio or basement with no mobile data, refresh once while online to cache the latest version (or keep the tab open).
Your local library and bookmarks are never deleted on refresh.
